资料目录（对齐官网「设置 → 岗位 / 简历 / 知识库 / 提示词模板」）

放文件的规则：

  资料\简历.pdf            简历只认 1 份，重新放一份就替换旧的（也支持 .docx / .md / .txt）
  资料\知识库\*.pdf        最多 2 份，每份 ≤3MB（.pdf / .docx / .md / .txt）
  资料\提示词_面试.txt      ≤2000 字，追加到面试回答的系统提示后面
  资料\提示词_笔试.txt      ≤2000 字，追加到笔试（截图）回答的系统提示后面

解析：PDF 用 pypdf、Word 用 python-docx，纯本地，不联网、不上传。
旧版 .doc（Word 97）读不了，请另存为 .docx 或 PDF。

生效：启动时读一次。改了文件重启程序（或改 .env 里的 MSX_PROFILE_DIR 指到别的目录）。

示例（提示词_面试.txt）：
  先一句话结论，再给 2 个要点。
  不要编造简历里没有的经历。
