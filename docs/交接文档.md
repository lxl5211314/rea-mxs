## 5. 架构与数据流

```
WASAPI loopback (soundcard, 16k mono, 100ms/块)
   │  threading.Thread
   ▼
VadSegmenter  自适应噪声底 noise=0.98*noise+0.02*rms
   │          阈值 max(SILENCE_RMS=0.006, noise*2.5)
   │          静音 hangover 0.6s 断句；语音段 ≥0.5s 才输出
   ▼
Asr           faster-whisper（cuda/fp16 优先，失败退 cpu/int8）
   │          峰值 <0.35 先归一化；initial_prompt 固定简体
   ▼
is_question() 疑问词表 + 问号；不命中不调 LLM（省 token）
   ▼
Brain         OpenAI 兼容 /chat/completions，stream=True，保留 6 条历史
   │          先结论后 2-3 点，≤140 字，第一人称口语
   ▼
Overlay       PySide6 无边框置顶 + WA_TranslucentBackground + WA_ShowWithoutActivating
             SetWindowDisplayAffinity(hwnd, 0x11)  ← 录屏/共享里消失
             跨线程用动态 QObject Signal
```

关键常量（`mvp.py` 顶部）：`SR=16000`、`BLOCK=1600`、`SILENCE_RMS=0.006`、`SILENCE_HANG=0.6`、`MIN_SPEECH=0.5`。

配置优先级：**系统环境变量 > `clone\.env` > 代码默认值**。

| 变量 | 默认 | 说明 |
|---|---|---|
| `OPENAI_BASE_URL` | `https://api.deepseek.com/v1` | 任意 OpenAI 兼容网关 |
| `OPENAI_API_KEY` | 空 | **必填**，空则只识别不作答 |
| `LLM_MODEL` | `deepseek-chat` | |
| `ASR_MODEL` | `faster-whisper-base` | 支持 `faster-whisper-tiny` 或绝对路径；`resolve_asr_model()` 自动映射到 `E:\aaa_msx\models` |

## 6. 已验证的实测数据

### 6.1 ASR 延迟（6.8s 提问，`bench_asr.py`）

| 模型 | 设备 | 加载 | 单次 | 质量 |
|---|---|---|---|---|
| tiny | cpu | 0.57s | 0.80s | 「面试关」「字我介绍」有错字 |
| base | cpu | 1.14s | 1.60s | 全对 |
| **base** | **cuda fp16** | 0.92s | **0.21s** | 全对 |
| small | cpu | 6.85s | 4.40s | 全对但太慢 |

### 6.2 端到端（`live_test.py`，耳机播放，不外放）

```
[capture] 采集中: 耳机 (LEITEYRE StarRing 2)
[asr] local:faster-whisper-base@cuda
[听到 0.38s] 你好,我是今天的面试官,先请你用一分钟做个自我介绍!
[屏] 思考中…
```

末字后 ≈ **1.0s** 判定出问题（0.6s hangover + 0.38s 转写），加 LLM 首字 0.3~0.5s → **首字 ≈ 1.4s**。

### 6.3 防截屏（`wda_test.py`）

```
普通无边框置顶:                    SetWDA=True  readback=0x11
半透明(WA_TranslucentBackground):  SetWDA=True  readback=0x11
半透明 + 点击穿透(WS_EX_LAYERED):   SetWDA=True  readback=0x11
```

结论：**不需要**商业版那套独立进程注入 + 看护，单进程即可。

## 7. 踩过的坑（照这个清单排查，别重走）

1. **`get_microphone(id=spk.name)` 抓到的是麦克风不是回环**（最致命）
   同名端点：`{0.0.0…}` 是渲染/回环，`{0.0.1…}` 是采集/麦克风。按名字会命中后者。
   症状：RMS 0.0069（源 0.13），互相关 -0.06，但 ASR 仍吐通顺句子（whisper 把 `initial_prompt` 复述成幻觉）。
   修法：**一律 `id=str(spk.id)`**。

2. **默认输出设备静音时 loopback 全 0 且不报错**（RMS=0.0000）。
   查：`IAudioEndpointVolume.GetMute()`；用 `setvol.py --show`。

3. **`pycaw.AudioUtilities.GetAllDevices()` 在本机直接 0xC0000005 崩溃**（exit=-1073741819，无输出）。
   只用 `AudioUtilities.GetSpeakers()`；枚举设备用 `soundcard.all_speakers()`。

4. **COM 线程模型冲突**：先 import soundcard（线程设 MTA）再 import comtypes →
   `OSError: [WinError -2147417850] 无法在设置线程模式后对其加以更改`；
   采集线程不初始化 COM → `RuntimeError: Error 0x800401f0`。
   修法：先 import comtypes/pycaw；工作线程调 `ole32.CoInitializeEx(None, 0x2)`。

5. **耳机插入后音量只有 0.070**，抓回电平仅源信号 2%。
   `setvol.py` 设 `SetMute(0)` + `SetVolume(0.75)`；ASR 前对峰值 <0.35 的段归一化。

6. **ctranslate2 有 GPU 但缺 `cublas64_12.dll`**：构造成功，`encode()` 时才抛
   `RuntimeError: Library cublas64_12.dll is not found or cannot be loaded`。
   修法：初始化后先跑 1s 静音验证，失败退 CPU；并装 nvidia-* 轮子 + `_add_cuda_dlls()`。

7. **HF 下载报 `FileMetadataError: Distant resource does not seem to be on huggingface.co`**（走 hf-mirror 时 HEAD 缺 `x-repo-commit`）。
   绕过：按 `https://hf-mirror.com/{repo}/resolve/main/{file}` 直接拉（脚本 `reverse\scripts\dl_model.py`，用法 `python dl_model.py Systran/faster-whisper-base E:\aaa_msx\models\faster-whisper-base`）。

8. **控制台 GBK 会把中文日志打成乱码**，且 PowerShell 输出可能被其它会话污染。
   对策：`$env:PYTHONIOENCODING="utf-8"`，输出 `| Out-File -Encoding utf8 xxx.log` 再用 read 工具看。

9. **`selftest.py e2e` 曾显示 `ASR 0.00s`**：f-string 先求值导致。已改为先 transcribe 再打印。

## 10. 待决策 / 待确认

- **ASR 走本地还是云端**：本地 base@cuda 已 0.21s 且免费；云端（SenseVoice/paraformer）在嘈杂会议里更稳，但要钱且要 key。建议本地默认、云端兜底。
- **问题检测要不要上模型**：规则版在多人会议（两个面试官互相说话）会误触发；商业版用带 `is_me` 的声纹判定。先规则 + 手动 `Tab` 覆盖，误报多了再上小分类模型。
- **是否要「隐身自检」**：本机三种样式都返回 `0x11`，但某些显卡驱动/远程桌面下会失效。建议加一个「截屏自检」：定时抓自己窗口，若画面非空白说明防截屏失效并提示（商业版 guard 干的就是这件事）。
- **发行形态**：单文件 exe 还是安装包；是否需要自动更新（商业版用 `/api/client-versions` + `download_and_launch_installer`）。
