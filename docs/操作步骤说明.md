# msx-clone 操作步骤说明（从零到可用）

适用目录：`E:\aaa_msx`。所有命令都在 PowerShell 里跑，先执行：

```powershell
$env:PYTHONIOENCODING="utf-8"
cd E:\aaa_msx\clone
```

（`PYTHONIOENCODING` 必设：Windows 控制台是 GBK，不设的话中文日志会乱码/丢字。）

## 一、安装

```powershell
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

依赖清单（见 `requirements.txt`）：soundcard、numpy、PySide6、keyboard、openai、
faster-whisper、ctranslate2、onnxruntime、pycaw、comtypes、Pillow、qrcode、mediapipe、opencv-contrib-python。

ASR 模型与动作捕捉模型已放 `E:\aaa_msx\models`（不用再下载）：

- `faster-whisper-base`（推荐，CUDA 下 6.8s 音频 0.21s）
- `faster-whisper-tiny`（更快，有错字）
- `face_landmarker.task`、`hand_landmarker.task`（动作捕捉）

## 二、配置（`.env`）

`clone\.env` 已配好可直接跑。关键项：

| 变量 | 值 | 说明 |
|---|---|---|
| `OPENAI_BASE_URL` | `http://127.0.0.1:19300/v1` | 本机「智能交付」relay |
| `OPENAI_API_KEY` | `local-yonyou-relay` | relay 固定 key |
| `LLM_MODEL` | `deepseek-v4.1-flash` | 推理模型，关掉思考后正文首字 0.5–1.5s |
| `LLM_EXTRA_JSON` | `{"thinking":{"type":"disabled"}}` | **必留**，否则思考占 3–5s |
| `LLM_WARM` | `1` | 保活：冷态 3.8s vs 热态 0.4s |
| `ASR_MODEL` | `faster-whisper-base` | 本地 ASR（relay 无云端转写） |
| `AUDIO_DEVICE` | 空/设备名子串 | 如 `耳机`；空=默认输出 |
| `ROLE` / `RESUME` | 你的岗位/简历 | 答案按此生成 |
| `ANSWER_STYLE` | `standard` | brief/standard/detailed/outline |
| `LLM_PROFILE` | `speed` | 灵动（快）/ `natural`=睿智（更口语、首字慢） |
| `QUICK_ANSWER` | `1` | 先出一句 ⚡ 速答（40 字内），完整答案随后覆盖 |
| `TRANSLATE` | `1` | 英/日/韩问题先给「【中文对照】」 |
| `THEME` | `dark` | 小窗样式：`dark`极暗 / `blue`蓝灰 / `large`大字，`Ctrl+Alt+Y` 切换 |
| `AUDIO_FALLBACK` | `1` | 20s 采不到声音自动切默认输出；8s 会先警告 |
| `MODE` | `interview` | `exam` 切笔试模式 |
| `MSX_PROFILE_DIR` | 空 | 资料目录，默认 `clone\资料` |
| `BANK_CSV` | 空 | 题库路径，默认 `clone\题库.csv`（也支持 `.xlsx`，自动跳「序号」表头） |
| `GESTURE` / `GESTURE_MODE` | `0` / `glasses` | 动作捕捉开关，`glasses`=扶眼镜 `blink`=眨眼 |
| `MOBILE` / `MOBILE_PORT` | `0` / `8765` | 手机联动页（**默认关**，要第二机位再开） |
| `MOBILE_HIDE` | `0` | `1`=第一题后自动藏本机窗口 |
| `TTS` | `0` | `1`=语音播报答案（双机位） |
| `LONG_Q` | 空 | `1`=长问句优化（等说完再答，默认关） |

改配置后重开 `mvp.py` 生效。

## 三、自检（先跑这个）

```powershell
python selftest.py deps     # 环境 + relay 可达
python selftest.py capture  # loopback 抓取（会播 1s 测试音）
python selftest.py asr      # 本地模型转写
```

## 四、启动

**Windows 直接双击 bat（推荐）**，不用开终端。总共只有两个入口：

| 双击 | 场景 | 链路 |
|---|---|---|
| `E:\aaa_msx\start.bat` | **面试** | 系统音频 → VAD → ASR → 问题 → 答案（约 20s，加载 ASR） |
| `E:\aaa_msx\start-exam.bat` | **笔试** | **只截图 → 视觉模型 → 答案**；不采集音频、不加载 ASR（约 3s） |

> 第一次跑 `start-exam.bat` 会先进准备页选语言/代码模式（写到 `.env` 的 `EXAM_LANG`/`EXAM_STYLE`）；
> 以后改配置：`start-exam.bat setup`。自检：`python clone\selftest.py deps|e2e|llm`；无界面：`python clone\mvp.py --no-ui`。
> 根目录这两个只是转发到 `clone\`，两处同名脚本行为一致。

和官网一致：**面试侠是同一个客户端，打开后自己选面试/笔试**；这里拆成两个 bat 只是为了少一次选择，
面试/笔试底层是两条独立链路（面试才需要 loopback + ASR；笔试不启动音频采集和 ASR）。
`start.bat` 里 `set MODE=interview`，`start-exam.bat` 里 `set MODE=exam`，**优先于 `.env` 的 `MODE`**。

bat 内部已经做了：`chcp 65001`、设 `PYTHONIOENCODING=utf-8`、切到脚本目录、
`python` 找不到时回退 `E:\python3.10.4\python.exe`、`.env` 缺失时自动从 `.env.example` 复制。

手动等价：

```powershell
python mvp.py              # 有浮窗
python mvp.py --no-ui      # 无浮窗
```

> 改 bat 时保持**纯 ASCII + CRLF**。cmd.exe 按 GBK 解析批处理文件，中文注释会让整行错位
> （报 `'保活' 不是内部或外部命令`），LF-only 换行会让 `rem`/括号块解析失败。

当前用的模型：

- **答题/视觉 LLM：智能交付 relay 的 `deepseek-v4.1-flash`**（`http://127.0.0.1:19300/v1`，
  关思考 + 保活，实机正文首字 0.83–1.45s）。relay 由 opencode 起，**先开着 opencode**。
- **ASR：本地 `faster-whisper-base` @ CUDA**（relay 没有 `/v1/audio/transcriptions`）。

手机联动默认关（`MOBILE=0`，终端不出二维码）；要第二机位再改 `.env`。

### 4.1 面试模式（`start.bat`）

约 20 秒就绪（加载 ASR + 预热 LLM）。就绪后：

- 浮窗出现（伪装标题 `Settings`，任务栏/Alt-Tab 隐藏）
- 终端打印 `[audio] 耳机 mute=0 音量=…`、`[capture] 采集中: …`、`[asr] local:faster-whisper-base@cuda`、
  `[llm] deepseek-v4.1-flash @ http://127.0.0.1:19300/v1`
- 面试官一开口，早触发先出答案，正文首字 0.8–1.5s

**测试**：`python live_test.py`（后台起程序、9 秒后播测试录音、结果写 `live.log`；
用 read 看，别直接 cat——控制台会乱码。）

### 4.2 笔试模式（`start-exam.bat`）

第一次跑 `start-exam.bat` 会先进准备页：选编程语言（自动识别 / Java / Python / C++ / … 共 18 种）和代码模式
（力扣=只写核心函数；ACM=含输入输出完整程序），写回 `.env` 的 `EXAM_LANG`/`EXAM_STYLE`。
以后要改：`start-exam.bat setup`（或 `python exam_setup.py`）。不改就用「自动识别 + 力扣」。

约 3 秒就绪，**没有 `[capture]` / `[asr]` 日志**，只有：

```
[mode] exam｜伪装标题 'Settings'｜语音播报 关
[exam] 截图作答：Shift+双击 整屏 / Alt+双击 窗口 / Ctrl+Shift+S 框选 / Shift+Alt+双击 长截图
[exam] 语言=自动识别｜代码模式=力扣（只写核心函数）｜取消 Ctrl+Shift+X
```

流程：把题放在屏幕上 → `Shift+双击`（或 `Alt+双击` 只截题目窗口，`Ctrl+Shift+S` 拖框只截题干）→ 浮窗流式出「思路 + 代码」。
`Shift+Alt+双击` 两次 = 长截图（60 秒内第二次，右键/Esc 取消；拼不上会自动把上下两段分别识别，不丢内容）；连续截图会排队（两张至少隔 1 秒），一张答完自动答下一张。
截图前浮窗会自动透明，截出来的图里不会有自己；框选层不抢焦点，浏览器不会因此判切屏。
答案第一行会标题型（`【题型】编程题/选择题/…`）：选择题、判断题只给「答案 + 一句依据」，不会啰嗦分析四个选项；
编程题如果模型漏了 `class Solution` / 函数签名，会自动带模板提示重试一次。
答案到达时浮窗只显示、不抢焦点；识别失败（模型回「未识别到题目」）不会覆盖上一题的可用答案，按 `Ctrl+Shift+R` 重截。
截图后浮窗顶部会贴一张原图缩略图（240×100 内等比），一眼确认没截错；下一张截图或新答案会替换它。
截图里没有题目（桌面/聊天/登录页）时只回「未识别到题目（看到的是：…），请重新框选题目区域」，不硬编。

想更隐蔽就设 `EXAM_SAFE=1`：强制关摄像头/手机端口/语音，窗口启动即隐藏并点击穿透，按 `F8` 才显示。

**窗口形态（默认常驻可见）**：`EXAM_GHOST=0` + `EXAM_IDLE=1`。没截图时窗口显示一张快捷键卡片（`Ctrl+Shift+1/2/3`/`Ctrl+Shift+S`/`Shift+双击`/`Alt+双击`/`Ctrl+Shift+G`/`Ctrl+Shift+R`/`Ctrl+Shift+L`/`F8`/`F9`/退出）。
按截图键的瞬间窗口自动 `hide()`，抓完再恢复，所以截出来的题目图里没有自己的浮窗。
窗口**不会自动消失**；答完题最简单是**直接关掉黑色控制台窗口**（实测关控制台 4 秒内进程清零），`Ctrl+Shift+Q` 两下是备选。
窗口右下角有两个小按钮：`小` = 迷你窗（430x250，字号同步变小，再点还原；等同 `Ctrl+Alt+M`），`隐` = 立刻隐藏（`F8` 叫回）。
会议共享/录屏里对方看不到这个窗口：WDA `0x11` 在本机 Win11 上对 WGC/DXGI 与 GDI BitBlt 均实测生效（详见 `clone/gdi_alpha_test.py`）。
想更隐蔽可改 `EXAM_GHOST=1`：启动即隐藏，答案到达才出现，`GHOST_HIDE_AFTER`（默认 10 秒）后自动消失，`F8` 随时叫出。

**看不清 / 要挪位置**：直接拿鼠标操作，不用记热键——左键按住窗口任意位置拖动移动，拖右下角 20px 内改大小，
`Ctrl+滚轮` 放大字号（窗口一起放大），`Alt+滚轮` 调透明度；`Ctrl+Alt+Y` 可切「大字清晰」主题。
窗口底板是自绘的深色圆角块，不会只剩一层浅色字浮在壁纸上（若真看到这种，说明跑的是旧进程，请重启）。

实测：整屏截图 0.39s，视觉首字 4.0s（冷）/ 1.4s（热），答非题目截图时正确返回「未识别到题目」。

笔试要点（`start-exam.bat`）：整屏 / 窗口 / 框选 / 长截图 四种截图，连续截图会排队
（「已排队第 N 张」），两张间隔 1 秒；答案给出「思路→代码→复杂度」。
笔试时**先按 `F9` 开点击穿透**，且 `GESTURE=0`（不要开摄像头，避免被平台检测到占用）。
`HOTKEY_SUPPRESS=1`（默认）会让这些热键不下发给浏览器——不会触发书签栏/另存为，也不会被页面键盘监控看到。
框选层是 `WindowDoesNotAcceptFocus`，拖框不会让浏览器失焦。

**考试当天建议：`SHOT_MOUSE=0`（关鼠标钩子，只用键盘截图）+ 不复制粘贴 + 不 Alt+Tab。**
平台的行为日志只看得到页面内事件：切屏、`paste`、`keydown`、`mousemove`。我们的截图是 OS 层 GDI
`BitBlt`，浏览器根本不知道；热键被 OS 吞掉，页面收不到 `keydown`；浮窗从不抢焦点，不产生切屏。
真正会被记下来的是：你自己切屏、你复制粘贴答案、你秒选选择题。详见 `docs/开发日志.md` §46。

### 5.1 直接读页面（DOM，比截图准）

牛客/力扣/ShowMeBug 这类页面，题干本身就在 DOM 里，读文字比截图识别准、也不会触发任何截图行为：

1. 用带调试端口的浏览器打开题目页（Chrome/Edge）：

   ```powershell
   cd E:\aaa_msx\clone
   python -c "import dom; dom.open_debug_browser('https://www.nowcoder.com/')"
   ```

   它会用独立配置目录 `E:\aaa_msx\browser-data` 启动，不影响你日常浏览器；调试端口 `9223`。
2. 登录、打开具体题目页，按 `Ctrl+Shift+D`。floating 窗里应出现答案，控制台打 `[dom] cdp 读到 N 字：…`。
3. 确认读得对，再想自动的话设 `DOM_AUTO=1`：每 2 秒看一次题干，题干变化且像问题才作答（默认关，避免误答）。

> 没开调试端口时走 UIA 兜底，但 Chrome 默认不向 UIA 暴露正文，只能读到地址栏——所以首选用 CDP。
> 读题不注入页面、不改 DOM、不发网络请求，只读 `innerText`。

### 7.3 眼神纠正（对应官网 /docs/eye-contact）

官网 Windows 方案本身就是调 **NVIDIA Broadcast** 的「目光接触」，不是自研。本机照做：
NVIDIA Broadcast → 摄像头 → 开启「目光接触」→ 会议软件摄像头选 `NVIDIA Broadcast`。
要求 RTX 2060+ / 8GB / Win10-11；低头角度太大时不纠正。

### 7.4 面试前四条铁律（官网 /docs/before）

1. **先开会议软件，再开本工具**（顺序反了可能抢不到音频设备）。
2. **全程不切换音频设备**（切了 loopback 会断，重新开始）。
3. 网页端只共享窗口；整屏共享必须用客户端隐身（`CLOAK=1`，本机 Win11 实测生效）。
4. 正式前 10 分钟跑一次 `python clone\selftest.py deps`（有测试录音再加 `e2e -w <wav>`），并自己说一句话确认浮窗出答案。

## 八、已知坑（遇到先看这）

- **听不到声音**：默认输出设备静音/音量为 0 → loopback 全 0 不报错。`python devices.py` 看现状，
  或 `python setvol.py 0.8` 强制把默认输出音量拉到 0.8。
- **耳机与扬声器**：本机有 2 个 loopback 设备，`AUDIO_DEVICE=耳机` 指定；不带耳机时把 `AUDIO_DEVICE` 留空走默认。
- **摄像头被占用**：Windows 一个摄像头只给一个进程。腾讯会议/Zoom 占着就读不到脸/手，
  需 Win11 26400+ 开「允许多个应用同时使用照相机」，或退出会议再测。
- **启动慢**：首次加载 ASR 模型 + 预热 LLM 约 20s 正常；动作捕捉开时再加 ~3s。
- **答案乱码/丢字**：`PYTHONIOENCODING` 没设。控制台看日志用 `python -c` 读文件，不要直接 `cat`。
- **relay 没起来**：`OPENAI_BASE_URL` 指 127.0.0.1:19300，需要本机跑 opencode 的「智能交付」provider；
  起不来就临时换 B 段直连 DeepSeek（见 `.env.example`）。
