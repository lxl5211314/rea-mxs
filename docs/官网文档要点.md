# 面试侠官网文档要点（2026-11-09 抓取）

来源：<https://mianshixia.cn/> 首页、`/changelog`、`/docs/*`（interview-assistant、written-exam、
gesture-capture、compatibility、desktop、dual-device、enhance-base、enhance-question-bank、
enhance-model、enhance-position、enhance-resume、enhance-knowledge、enhance-prompts、
advanced、eye-contact、before、faq）。本文只记录事实，作为本地实现的对照基准。

## 1. 产品形态

- Windows 桌面端 5.0、手机 App、网页/平板三端，订阅数据云端同步。
- 卖点：系统音频听题、⚡ 速答、截图答题、动作捕捉、防截屏隐身、手机联动双机位、
  简历+知识库、意图识别、表达润色（STAR + 数字）、外语面试翻译对照、AI 眼神纠正。
- 宣传数据：340 万+ 企业真题、790+ 企业（题库规模，非本地能力）。

## 2. 面试模式（/docs/interview-assistant）

- 声音来源：系统音频（默认）或麦克风；「音频设备」选会议软件外放的那个输出设备。
- 流程：先开会议软件 → 确认声音/岗位/简历/题库 → 开始面试 → 任务栏图标消失 →
  左侧问题、右侧答案；闲聊寒暄不出现。
- 退出 `Ctrl+Shift+Q`（3 秒内连按两次）；小窗无按钮，全靠快捷键。
- 答案先出「⚡ 速答」，再被完整回答覆盖；可复制/重答。
- 面试中临时写代码：`Shift+双击` 整屏截图，结合面试上下文给思路+代码。
- 系统音频长时间采不到会自动切「外放单路模式」。

## 3. 笔试模式（/docs/written-exam）

- 准备页设编程语言（默认自动识别，可指定 18 种）与代码模式
  （力扣=只写核心函数；ACM=含输入输出的完整程序）。
- 四种截图：整屏 `Shift+双击`、窗口 `Alt+双击`、长截图 `Shift+Alt+双击` 两组
  （60 秒内第二次否则取消，Esc 可取消）、动作捕捉。
- 连续截图排队：「已排队第 N 张 · 上一题完成后自动分析」，两张间隔 1 秒。
- 取消当前截图/作答 `Ctrl+Shift+X`，已出的部分答案保留。
- 题型：编程、技术类笔试、普通笔试题（行测/图形推理）、面试中临时写题。
- 识别不到时列出：桌面、视频会议画面、登录页、简历、PPT、聊天气泡、文件管理器。
- 计费按题 1 分钟，同题 10 分钟内重复不重复扣；Windows 笔试小窗无最小化/关闭按钮（故意）。

## 4. 动作捕捉（/docs/gesture-capture）

- 默认关闭；本机识别，画面不上传；0.3.84+。
- 扶眼镜/按鼻梁：指尖停住约 0.5s；超过 5s 当托脸不触发；屏幕小圆环走满即截屏。
- 快速眨眼两次：间隔 ≤0.5s、整串 ≤1.5s、前 1 秒内无其他眨眼、只算双眼同时闭合。
- 触发后 3–4 秒冷却；正式使用无提示音无弹窗；「试一试」连续成功 3 次提示「手感稳了」。
- 摄像头只在面试/笔试进行中打开，退出即关；Windows 默认摄像头独占
  （Win11 24H2 26100.3321+ 可开「允许多个应用同时使用照相机」；Win10 无）。
- 手机联动里也可选手机摄像头识别。

## 5. 隐身与兼容（/docs/compatibility）

- `SetWindowDisplayAffinity` 类能力：共享整屏时答案小窗对对方不可见；任务栏图标消失。
- Win11 / Apple 芯片最稳；Win10(2004+) 与 Intel Mac 不保证。
- 腾讯会议勾「视频流畅度优先」；Zoom 用「截屏模式→带窗口筛选功能的截屏」；
  钉钉/飞书/百度如流/Google Meet/牛客/LeetCode/HackerRank/CoderPad 默认完全隐身。
- 国考云不支持（会强杀其他程序）。
- 伪装：窗口标题（默认 `Settings`）、应用图标、样式预设（极暗低调/护眼蓝灰/大字清晰）、
  字号/字色/代码块主题/透明度/大小、桌面预览。
- 有些会议软件鼠标点到别处也算切屏 → 全程热键/手机/动作捕捉。

## 6. 快捷键（/docs/desktop）

`Ctrl+Shift+B` 显隐；`Ctrl+Shift+Q` 退出；`Ctrl+Shift+↑/↓` 上/下一题；`Ctrl+Shift+P` 钉住；
`Ctrl+Shift+G` 强制提交当前文字；`Ctrl+Shift+X` 取消当前截图/作答；`Ctrl+Alt+=/-` 透明度；
`Alt+Shift+=/-` 缩放；`Alt+Shift+↑/↓` 答案滚动；`Shift+方向键` 移动；`Ctrl+Shift+L` 展开/收起问题列表；
`Ctrl+Shift+/` 快捷键说明；`Ctrl+Alt+Y` 切主题。冲突会自动换一组并提示。

## 7. 双机位（/docs/dual-device）

1. 降低透明度（面试+笔试，`Ctrl+Alt+=/-`，极暗低调预设）。
2. 答案挪到手机（手机联动 +「开始后隐藏电脑窗口」）。
3. 语音播报（仅笔试，蓝牙耳机，小窗完全隐藏；退出 `Ctrl+Shift+Q`，重复上一句 `Ctrl+Shift+8`；
   与手机联动互斥）。
- 第二机位 1.5–2m、高 1.2–1.5m，耳机戴远离第二机位一侧。

## 8. 设置九栏（/docs/advanced）

通用、声纹、基础配置、模型、岗位、简历、知识库、题库、提示词模板。
推荐配置顺序：岗位/简历 → 风格/模型 → 知识库/题库/提示词。

| 项 | 规则 |
|---|---|
| 回答风格 | 极简 ≈200 字 / 标准 ≈400 字 / 详细 ≈800 字 / 大纲 ≈300 字（要点列表） |
| 模型 | 灵动（默认，速度优先）/ 睿智（效果优先，更口语，首字稍慢） |
| 岗位 | 影响回答侧重点 + 知识库/题库匹配方向；预设前端/后端/产品/UI/测试/数据分析 |
| 简历 | 1 份；PDF / Word(`.doc/.docx`) / Markdown；≤3MB；扫描图不建议 |
| 知识库 | ≤2 份；同上格式/大小；适合 JD、项目文档、技术方案、行业材料 |
| 题库 | 「问题,答案」两列 CSV/TSV/Excel；≤3MB、≤500 条；表头可无；「序号」列自动跳过 |
| 提示词 | 面试/笔试各 ≤5 条、同类一次只启用 1 条、单条 ≤2000 字；手机端无编辑入口 |
| 翻译对照 | 默认开；英文内容自动中文对照，中文无额外开销 |
| 长问句优化 | 实验项，默认关；等较长问题说完再答 |

题库匹配三步：一模一样 → 意思几乎相同（AI 确认）→ 才原样用；拿不准只当参考不改写。

## 9. 手机联动（/docs/mobile-link）

- 电脑出二维码 + 6 位配对码（闲置 5 分钟换码）；手机同 Wi-Fi；一台电脑同时只接一台手机。
- 配对后「开始后隐藏电脑窗口」默认开；电脑点开始先 3 秒提示再隐藏。
- 手机端：状态、答案卡（流式、左右滑动回看、回到最新）、
  底部「截图出答案/隐藏电脑/长按显示/动作捕捉/遥控电脑」。
- 遥控面板：透明度/窗口/答案三摇杆（长按连发）、方向键、区域/全屏/长截图、上/下一题、
  主题/题目列表/快捷键/退出。
- 只电脑→手机推内容；手机→电脑只有遥控指令；「强制提交当前文字」只能电脑按。
- 手机掉线后电脑窗口保持隐藏，不自动弹回。

## 10. AI 眼神纠正（/docs/eye-contact）

- Windows：**不自研**，最低 RTX 2060 + Win10/11 + 8GB，用 NVIDIA Broadcast 开「目光接触」，
  会议软件选虚拟摄像头；大角度/低头不纠正。
- macOS：需 M1+、macOS 13+，用「面试侠摄像头」。

## 11. 面试前四铁律（/docs/before）

1. 先开会议软件，再开面试侠。
2. 全程不切换音频设备。
3. 网页端只共享窗口（整屏共享必须用客户端隐身）。
4. 一个账号同一时间只能一台设备。正式前 10 分钟做一次完整测试。

## 12. FAQ（/docs/faq）

- 一句都没识别到不扣时长。
- 网页端不能做笔试。
- 客户端系统音频模式不听自己麦克风。
- 手机联动后电脑窗口消失是正常，`Ctrl+Shift+B` 找回。
