# 快捷键速查（msx-clone）

> 适用：`E:\aaa_msx\start.bat`（面试）与 `E:\aaa_msx\start-exam.bat`（笔试）。
> 标记说明：🟢 常用 / 🟡 进阶 / 🔴 退出与危险操作。
> 除标注外，所有组合键默认被程序吞掉（`HOTKEY_SUPPRESS=1`），浏览器收不到，不会触发书签、另存为等副作用。

---

## 一、最常用的 10 个（背这一张就够）

| 按键 | 作用 | 场景 |
|---|---|---|
| **Ctrl + Shift + 1** | 整屏截图 → 出答案 | 笔试主力（当前默认） |
| **Ctrl + Shift + 2** | 只截鼠标所在的窗口 | 题目在独立窗口里 |
| **Ctrl + Shift + 3** | 长截图（同位置再按一次） | 一屏放不下的题 |
| **Ctrl + Shift + S** | 框选一块区域截图 | 只截题干，快 |
| **F8** | 显示 / 隐藏窗口 | 临时收起来 |
| **Ctrl + Shift + Q**（3 秒内按两次） | 退出程序 | 结束考试 |
| **Ctrl + Shift + ↑ / ↓** | 上一题 / 下一题 | 回看历史答案 |
| **Ctrl + Shift + C** | 复制当前答案 | 粘贴到答题框 |
| **Shift + 方向键** | 移动窗口 20px | 挡题了挪一下 |
| **Ctrl + Alt + M** | 迷你窗 / 标准窗 | 挡住题干时 |

> 当前 `.env` 是 `SHOT_MOUSE=0`（考场低痕迹）：**鼠标双击手势已关闭**，截图一律用 `Ctrl+Shift+1/2/3`。
> 想要回双击手势就把 `SHOT_MOUSE` 改回 `1`（Shift+双击有真实鼠标事件落到页面上，行为日志里比较显眼）。

## 二、笔试：截图

| 按键 | 作用 | 说明 |
|---|---|---|
| Ctrl + Shift + 1 | 整屏截图 | 当前默认主力，最稳 |
| Ctrl + Shift + 2 | 窗口截图 | 截鼠标下的窗口；窗口小于 200×120 时退化为整屏 |
| Ctrl + Shift + 3 | 长截图 | 在**同一位置**再按一次完成拼接；两次间隔 ≥1 秒 |
| Ctrl + Shift + S | 框选截图 | 出现全屏遮罩，拖一个框；不抢焦点，不会造成切屏 |
| Shift + 双击 | 整屏截图 | 需 `SHOT_MOUSE=1`（当前默认 0，已关闭） |
| Alt + 双击 | 窗口截图 | 同上，需 `SHOT_MOUSE=1` |
| Shift + Alt + 双击 | 长截图 | 同上，需 `SHOT_MOUSE=1` |

> 双击判定参数：两次点击间隔 < 0.85 秒、位移 < 24px。
> 截图瞬间浮窗会自动隐藏，抓完恢复；整屏共享里看不到窗口（WDA `0x11`）。
> 同一时间只处理一张，连续截图有 1 秒节流。

| Ctrl + Shift + L | 题目列表（再按一次返回） |
| Ctrl + Shift + U | 追问预判（列出可能的追问 + 要点） |
| Ctrl + Shift + D | 从浏览器页面直接读题（DOM，优先 CDP；只读不改页面） |

| Ctrl + Shift + H | 弹出快捷键帮助 |

## 五、面试（MODE=interview）

面试模式不需要手动触发：听到问题 → 自动断句 → 出答案。

| 按键 | 作用 |
|---|---|
| Ctrl + Shift + G | 强制提交当前听到的文字（ASR 还没断句时手动触发） |
| Ctrl + Shift + R | 重答上一题 |
| Ctrl + Shift + U | 追问预判 |
| Ctrl + Shift + ↑ / ↓ | 上一题 / 下一题 |
| Ctrl + Shift + P | 钉住当前答案 |
| Ctrl + Shift + C | 复制答案 |
| 其余窗口键 | 与笔试完全一致 |

## 六、退出与启动参数

| 操作 | 说明 |
|---|---|
| Ctrl + Shift + Q（3 秒内两次） | 🔴 退出本场（会先存窗口位置） |
| 双击 `stop-exam.bat` / 桌面「关闭msx-clone」 | 🔴 强杀 mvp + guardian + 宿主 cmd（控制台隐藏时也能关） |
| `start-exam.bat` | 笔试，**默认带守护**（崩溃 0.5s 自动重启） |
| `start-exam.bat plain` | 笔试，只跑一次（调试） |
| `start-exam.bat guard` | 笔试，强制守护 |
| `start-exam.bat setup` | 重新选语言 / 代码模式 |
| `start.bat` | 面试 |

> 控制台默认已隐藏（`CONSOLE_HIDE=1`），所以没有「关窗口退出」这条路：程序内 `Ctrl+Shift+Q` 两下，程序外双击 `stop-exam.bat`。
> 窗口默认 800×620；小于 560×400 的迷你态存档不会被下次启动还原。
> 日志：`E:\aaa_msx\clone\run.log`。

## 七、注意事项

1. **吞键**：`HOTKEY_SUPPRESS=1` 时，上面这些组合键不会传到浏览器。唯一不吞的是 `Shift+方向键`（编辑器和输入框要用）。
2. **鼠标手势默认关闭**：`SHOT_MOUSE=0`。要找回双击截屏，把 `.env` 里改成 `SHOT_MOUSE=1` 并重启；开了以后两次点击间隔 < 0.85 秒、位移 < 24px 才算一次双击。
3. **别用鼠标点浮窗**：会让浏览器失焦，可能被记一次切屏。要操作窗口用热键，或先 `F9` 开点击穿透。
4. **隐藏后找不回**：先按 `F8`，再按 `Ctrl+Alt+S`，都不行就再双击一次 `start-exam.bat`。
5. **关不掉**：`Ctrl+Shift+Q` 两下；还不行就双击 `stop-exam.bat`（桌面有「关闭msx-clone」快捷方式）。
6. **全屏游戏/远程桌面软件**可能抢占全局热键；冲突时以 `Ctrl+Shift+1/2/3` 和 `Ctrl+Shift+Q` 为主。
